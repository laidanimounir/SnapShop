## 1. ما هو المشروع

متجر إلكتروني جزائري للملابس والأحذية، **الدفع عند الاستلام فقط**، مبني بـ **Next.js** و **Supabase**. المشروع فيه جزءان في نفس التطبيق: **واجهة المتجر** للزوار، و**لوحة تحكم إدارية** داخلية (`/admin`) لقراءة الطلبات والمنتجات والتقييمات، إضافة إلى **منشئ صفحات هبوط** لكل منتج (سحب وإفلات + معاينة مباشرة) مع صفحة عامة عربية RTL لكل عرض.

## 3. نقطة البداية (الجرد الأولي)

عند بدء العمل، كانت قاعدة البيانات تحتوي على **10 جداول** مع خصم مخزون ذرّي (atomic)، لقطة أسعار عند الشراء (price snapshots)، و**58 ولاية** للشحن. الثغرات التي وُجدت ولم تكن مغطاة:

- منشئ صفحات الهبوط غير موجود إطلاقاً.
- لا يوجد قفل على المخزون بالكامل، ولا حراسة على صور المنتجات.
- لا يُستعاد المخزون عند مسار `delivered → returned`.
- فهارس (indexes) مكرّرة أو معطوبة غير منظّفة.

## 5. ما تبقّى (بالترتيب المقترح)

### مرحلة العمليات
1. **التصنيفات، العلامة الاختيارية، البلديات، الحذف الناعم (soft delete) للمنتجات.**
2. **المرتجعات/التبديل** مع دافع شحن ديناميكي (بائع/عميل/مقسّم) + دفتر حركة المخزون + سجل النشاط.

### قبل الإطلاق
- ترقية `next` / `vitest` / `tailwind` (نتائج `npm audit`).
- حماية من الطلبات الوهمية (Turnstile أو Cloudflare) قبل حملات الإعلان.
- حذف كل بيانات الاختبار.
- تعيين slug حقيقي بدلاً من `demo-offer`.
- إعدادات Supabase المدفوعة (حماية كلمات المرور المسرّبة) عند الترقية.

### لاحقاً
- إشعارات Telegram.
- تكامل شركة التوصيل (المزوّد الحالي `ecotrack` مجرّد هيكل غير مُنفّذ).

## 7. قيود معروفة / تحذيرات

- رفع الصور مدعوم فقط للنطاقات التي تنتهي بـ `supabase.co`.
- معاينة الجوال مجرّد ضبط عرض، ليست viewport حقيقياً (تحتاج iframe).
- العدّاد التنازلي (`Countdown`) شكلي فقط.
- محدّد المعدّل (rate limiter) في الذاكرة فقط.
- **لا تشغّل `npm run build` أثناء عمل `npm run dev`** (يفسد مجلد `.next`).
- لا تُرفع `.env.local` أبداً، ومفتاح `service_role` يجب ألّا يصل للمتصفح إطلاقاً.

## 8. كيف تشغّل المشروع

- تشغيل خادم التطوير: `npm run dev` ثم افتح `http://localhost:3000`.
- بذر صفحة هبوط تجريبية: `node --env-file=.env.local scripts/seed-landing-page.mjs`.
- الاختبارات: `npm test` (Vitest).
- البناء: `npm run build` ثم `npm start`.
- ملفات الـ migrations في: `supabase/migrations/` (0001 → 0014).
